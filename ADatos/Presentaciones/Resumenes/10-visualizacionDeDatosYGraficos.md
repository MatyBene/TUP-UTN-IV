# Visualizacion de los datos

- Ejes: vertical y horizontal. Tienen las unidades de medidas de los datos
- Leyenda: explica lo que se esta viendo en cada elemento del grafico
- Etiquetas: indica el valor de cada punto en el grafico permitiendo entender valores especificos de la base
- Eje secundario: es un eje horizontal adicional que podremos utilizar cuando los valores tienen diferente unidad de medida

## Tipos de graficos

### Grafico de barras

Es de gran utilidad cuando queremos observar valores entre distintas variables. El histograma es muy utilizado para analizar frecuencias.

### Grafico ded torta

Se utiliza para analizar porcentajes y proporciones de una variable.

### Grafico de lineas

Se utilizan para analizar y comparar evoluciones dentro de nuestros datos.

### Grafico de dispersion

Nos permite analizar los valores entre dos variables determinadas y asi entender como se agrupan nuestros datos.

### Grafico de heatmap

Utiliza colores para representar los valores de una variable en una matriz o tabla. Es muy util para detectar patrones, tendencias, valores altos o bajos de forma visual rapida y clara. Sirven para detectar patrones visuales en grandes volumenes de datos, identificar zonas con mayor o menor intensidad. Se usa para evaluar desempeño de productos o regiones, analizar comportamiento de usuarios, ver frecuencia o intensidad de eventos.

### Grafico de cajas

Nos permite analizar variables en mayor grado de detalle a traves de percentiles.

### Nube de palabras

Nos permite ver las palabras o frases mas relevantes en una base de datos.

## Consejos practicos

Caracteristicas que deben tener tus visualizaciones:

- Perceptivas: Deben poder capturar relaciones entre las variables
- Claras: Habilidad de distinguir visualmente los elementos graficos
- Consistentes: Presentar un formato o logica estandar a visualizaciones anteriores de la misma tematica
- Eficientes: Posibilidad de mostrar patrones complejos de una forma clara y simple
- Necesarias: Demostrar la necesidad del grafico, afirmando que es la mejor forma de visualizar estos datos
- Confiables: Determinar el valor verdadero de los datos que estemos mostrando

## Consideraciones

- Comparacion: Lo que queremos mostrar se parece a una comparacion entre variables/situaciones (graficos de barras o de lineas)
- Relaciones: Estamos buscando encontrar relaciones entre variables de nuestra base (graficos de dispersion o heatmaps)
- Distribucion: Queremos entender como estan distribuidos nuestros datos (histogramas o graficos de cajas)
- Composicion: Para entender como son los valores de nuestra base segun alguna caracteristica (graficos de torta o de barras apiladas)
